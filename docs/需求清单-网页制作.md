# 网页制作需求清单

> 用途：你按这份清单说话，我就能直接开工，不用来回追问。
> 范围：只覆盖**网页本身**（结构 / 视觉 / 动效 / 响应式 / 文案 / 无障碍）。
> 不含：内容录入工具、Git 部署、图片压缩流水线——那些属于「运维」，需要时单独提。

---

## 0. 怎么用

1. **顺序**：先给 0 号（定位），再给 1 号（骨架）和 2 号（视觉），3 号按区块逐个说。4–6 号没特殊要求就一句话带过。
2. **必填 vs 可选**：标 ✅ 的缺了我会停下来问；标 ○ 的我会按默认值补，并告诉你补了什么。
3. **一句话里别只放形容词**。"高级一点""再炫一些"我无法执行，附 A 有翻译表。
4. **改版用 7 号卡片**，不要重新描述整站。

## 1 号卡｜项目定位 ✅

一段话讲完，五个空：

| 字段 | 你要说的 | 本次取值 |
|---|---|---|
| 是什么 | 一句话，别用"平台/系统"这类大词 | 个人设计作品集，单页长滚动 |
| 给谁看 | 招聘方 / 客户 / 同行 / 自己存档 | 招聘方与潜在客户 |
| 看完要干什么 | 投简历 / 询价 / 只是浏览 | 留下印象 → 点邮箱或看简历 |
| 内容量级 | 大概多少件作品、多少张图、多少 MB | 139 件作品，素材约 276 MB |
| 长期性 | 一次性页面 / 会持续更新 | 长期，会持续加作品 |

> 句式：「做一个 ___，主要给 ___ 看，希望他们看完 ___。内容大概 ___。」

## 2 号卡｜页面骨架 ✅

**必须给一张区块表**，顺序即页面顺序。每个区块说四件事：放什么、多高、有没有固定结构、能不能自由发挥。

| # | 区块 | 放什么 | 高度 | 结构约束 |
|---|---|---|---|---|
| 1 | 首屏 | 姓名 + 一句话定位 + 3 个数字 + 背景动效 | 整屏 | 标题必须拆行，不许居中对称 |
| 2 | 关于 | 头像、自述、技能、邮箱/微信/简历入口 | 整屏 | 联系方式固定三行 |
| 3 | 平面设计 | 品牌 VI、艺术海报、Icon、字体 | 多屏 | VI 每套固定 7 张九宫格 |
| 4 | 电商设计 | 商品套图、详情页、营销海报、溶图、Banner | 多屏 | 溶图必须成对（前/后） |
| 5 | 尾页 | 致谢 + 联系方式 + 回顶部 | 整屏减页脚 | 不许放导航 |

**你需要额外说明的三件事：**

- **哪些区块是"作品墙"**（图多、可点开大图），哪些是"叙事段"（文字为主）。
- **哪些区块有硬结构**：例如"VI 每套必须 7 张、排成九宫格、首图占两列"——这种不能由我发挥。
- **空的地方能不能填**：例如工作经历为空时，是留白还是我编一段。**默认：留白，不编造。**

## 3 号卡｜视觉语言 ✅

**第一条必须是风格名**，从我手册的风格词汇里选（Swiss / Editorial / Bento / Dark-Tech / Neo-Brutalism / Acid / Liquid Glass / 3D CGI / Art Nouveau / Art Deco / Frutiger Aero / Y2K 等），再说气质。

| 字段 | 你要说的 | 本次取值 |
|---|---|---|
| 风格名 | 一个词，别用组合长句 | Dark-Tech × Editorial |
| 气质 | 三个词以内 | 克制、冷、可读优先 |
| 参考 | 1–3 个 **URL 或截图**，说清参考的是哪一部分 | 暗色作品集 + 杂志排版 |
| 底色 | hex，不要"深色" | `#08060f` |
| 主强调 | hex，用在序号/描边/高亮 | `#c4a7ff` |
| 文字三级 | hex × 3 | `#f2f0f7` / `#a09aae` / `#6f6880` |
| 字体 | 西文 display + UI，中文怎么处理 | Anton + Space Grotesk + 中文系统黑体 |
| 大标题 | 行高、字距 | 行高 0.92，西文 -0.045em，中文 +0.01em |
| 版式倾向 | 对齐/留白/网格 | 左对齐、非均匀间距、允许不对称 |

**禁用清单（比正向描述重要，请单独写一行）**

> 本次：不要廉价饱和紫、不要紫蓝渐变、不要滥用毛玻璃、不要 Inter、不要居中对称、不要均匀间距。

## 4 号卡｜动效与交互 ✅（按区块逐个说）

每个区块一行，四件事：**效果 / 触发 / 强度 / 可重复性**。

| 区块 | 效果 | 触发 | 强度 | 可重复 |
|---|---|---|---|---|
| 首屏 | WebGL 纤维背景 + 画布文字 | 常驻 | 重 | — |
| 关于 | Three.js 色带 + 逐字折叠 | 滚动入场 | 中 | 进入播放，离开归零，可重播 |
| 平面 | 抖动背景 + 弧形海报画廊 + 叠放卡 | 滚动 / 滚轮横切 | 重 | 同上 |
| 电商 | 线波背景 + 纵深卡组 + 跑马灯 | 滚动 + 自动轮播 | 重 | 同上 |
| 尾页 | 涟漪网格 + 描边文字 | 点击涟漪 | 中 | — |

**必须交代的三条：**

- ✅ **强度分档**：轻（12–24px 位移 + 淡入）/ 中（视差、缩放、逐字）/ 重（WebGL、3D、逐帧）。**别整页都重**，重效果集中在首屏和 1–2 个区块。
- ✅ **可重复性**：入场动效是"只播一次"还是"离开归零、回来重播"。这条不定，我会按默认（可重播）做。
- ✅ **降级态度**：低端机你想"效果打折"还是"布局塌掉也不能打折"。默认：砍 WebGL，保布局与文字动效。

## 5 号卡｜响应式与设备 ✅

| 字段 | 你要说的 | 本次取值 |
|---|---|---|
| 谁在用手机 | 大概比例 | 一半以上，微信里打开居多 |
| 断点 | 只需说移动/桌面两档，或给具体宽度 | ≤900px 一档 |
| 移动端可砍什么 | 明确授权 | 关视差、关 WebGL、关毛玻璃、关噪点 |
| 移动端不能砍什么 | 反向约束 | 文字动效、图片可点开、双语切换、菜单可用 |
| 首屏预算 | 多少 KB / 多少秒 | 首屏图 1 MB 内 |

> 一句话够用：「手机上不要卡，效果可以打折，但文字动效和看图功能不能少。」

## 6 号卡｜内容与文案 ✅

- ✅ **语言**：单语 / 双语。双语要说明是否**每条都要翻**（本次是全量，英文缺键会编译报错）。
- ✅ **文案谁写**：你给原文，还是我先写你再改。默认：短句我写，长文建议你给。
- ✅ **素材来源**：给一个**目录路径**，说明是否只读（本次 `E:\作品集` 只读，任何脚本不许改它）。
- ✅ **数量口径冲突怎么办**：需求写 3 套、实际 5 套 —— 按实际全量 / 按需求砍 / 补拍。**这条必须提前定**，否则做出来对不上。
- ✅ **不许编造的内容**：履历、客户名、奖项、数据。默认全部留空。

## 7 号卡｜验收标准 ✅

说清"什么样算做完"，我按这个跑测试。

- 键盘能走完所有交互；焦点始终可见；Esc 能关弹窗；关闭后焦点回到触发按钮
- 支持"减少动态"系统设置（此时不播动效，但不能白屏）
- 图片都带固定宽高比（不跳动）
- 控制台无报错；移动端无横向溢出
- 点开大图可缩放、可翻页

## 8 号卡｜改版 / 变更请求 ✅

**别重述整站。** 用这六格，一段话说完：

```
对象：哪个区块、哪个设备
现状：现在是什么样，什么时候出现
期望：改成什么样（要可验证，别说"好一点"）
参考：截图 / URL / 一句类比
不许动：这次不许改的部分
验收：我怎么确认改好了
```

> 实例：
> 「对象：电商 Banner 区，手机。现状：滚动时整片明暗闪烁，安卓原生浏览器最明显。期望：滚动时画面稳定，不出现整块跳动。参考：同页首屏滚动是稳的。不许动：卡片纵深和自动轮播保留。验收：手机滑过这一段不再闪。」
>
> 这条描述之所以有效：**给了设备、给了对照（首屏是稳的）、给了不许动的边界**，我才能定位到是背景层重绘而不是整个轮播换掉。

## 附 A｜形容词 → 可执行需求（翻译表）

| 你说 | 我需要你补什么 |
|---|---|
| 要高级 | 参考站 URL + 底色/强调色 hex + 禁用清单 |
| 要炫 | 强度档位（轻/中/重）+ 集中在哪几个区块 + 手机能不能砍 |
| 简洁一点 | 砍内容还是砍留白？还是砍效果？ |
| 有设计感 | 版式倾向（对齐方式、是否允许不对称、间距是否均匀） |
| 科技感 | 是暗底+网格+辉光，还是数据可视？两者完全不同 |
| 大气 | 字号级差（display 字号是正文的几倍）+ 首屏信息量 |
| 参考这个站 | 说清参考的是**布局**、**配色**、还是**动效**，三者经常不兼容 |
